# Motor Luxe Yorkshire Limited — website preview

The rendered preview of Motor Luxe's rebuilt website (Parkside template). Static HTML copied from the
PHP build so it can be viewed by anyone with the link, no login and no server.

**Live preview:** https://dealersales.github.io/motor-luxe-preview/

What to look at:

- the home page: stock search, the banner, the contact/opening-hours card
- **Stock** and any vehicle page
- **Sell your car**, **Warranty**, **About us**
- open it on a phone — most of their traffic is mobile

Notes on this preview:

- Stock filters do not work here (they need PHP). The stock page and every vehicle page do.
- The enquiry form does not send from this copy.
- This is a review build. Nothing has been put on motorluxeyorkshirelimited.co.uk.
